{% if not tg.token_set %}

TELEGRAM_BOT_TOKEN=token-dari-BotFather
{% endif %} {% if tg.token_set and not tg.chat_verified %}
Langkah 2 — verifikasi chat kamu

Kirim pesan apa saja ke @{{ tg.bot_username }} (mis. halo). Balasan bot memuat chat ID kamu — tambahkan ke .env lalu restart server:

{% if tg.last_chat_id %}

Chat ID terdeteksi dari chat terakhir ({{ tg.last_chat_name|default:"tanpa nama" }}):

TELEGRAM_ALLOWED_CHAT_IDS={{ tg.last_chat_id }} {% else %} TELEGRAM_ALLOWED_CHAT_IDS=123456789 {% endif %}

Demi keamanan, pesan dari chat lain diabaikan — hanya kamu yang bisa mencatat transaksi lewat bot.

{% endif %}
Cara mengirim transaksi

Ketik ke bot dengan format [pemasukan|+] kategori jumlah [tanggal]:

  • makan siang 25rb → pengeluaran “makan siang” Rp 25.000
  • +gaji 5jt → pemasukan “gaji” Rp 5.000.000
  • sewa rumah 1.500.000 05-07-2026 → dengan tanggal tertentu
  • belanja 100rb kemarin → tanggal relatif

🔒 Jika kategorinya belum ada, bot tak akan langsung membuatnya — ia bertanya dulu: simpan (untuk seterusnya) atau bulanan (hanya bulan ini, dihapus otomatis) — agar kategori random tidak menumpuk.
